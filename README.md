# Сборщик товаров

Программа собирает название, цену, характеристики, наличие и ссылку товаров и сохраняет их в Excel и CSV.

## Установка
1. Запустите `ProductScraper-Setup-1.0.0.exe` (Windows 11 x64). Если Windows пишет «Защитил ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае» (программа не подписана).
2. Следуйте шагам мастера. Интернет при установке не нужен, он нужен при работе.
3. Запуск: Пуск → «Product Scraper».

## Работа
1. Выберите категорию (список подгружается с сайта; «Обновить список» — загрузить заново).
2. Укажите число потоков (1–5), лимит записей (0 — без лимита), паузу между запросами и при необходимости фильтры: цена, слово в названии, «Только в наличии».
3. Нажмите «Запустить». Следите за статистикой и журналом.
4. «Остановить» — безопасная остановка, прогресс сохраняется.
5. «Продолжить…» — выберите папку прежнего запуска (в ней файл progress.db), и сбор продолжится с места остановки.

## Где результаты
Папка по умолчанию: `C:\Users\<имя>\ProductScraper\runs\<дата_категория>\`
- `products.xlsx` и `products.csv` — таблицы (CSV с разделителем «;», открывается в Excel);
- `log.txt` — журнал событий;
- `progress.db` — прогресс для продолжения;
- `backup\` — резервные копии базы и предыдущих версий таблиц.
Кнопка «Открыть папку» открывает её из программы.

## Если сайт ограничил доступ
Программа сама остановится (статус «Сайт ограничил доступ»), сохранит всё собранное и выгрузит таблицы. Подождите и нажмите «Продолжить…».

## Если что-то не работает
Откройте `log.txt` нужного запуска. Если программа не открылась — файл `C:\Users\<имя>\ProductScraper\crash.log`.

## Удаление
Параметры Windows → Приложения → Product Scraper → Удалить. Папка `ProductScraper` с результатами в вашем профиле не удаляется.
